# 專業撞球計分系統
## [開啟計分頁面](https://fengying208.github.io/14-1Scoreboard/)
---

## 操作說明

| 效果 | 動作及觸發位置 |
| :--- | :--- |
| **該選手單局得分 +1**，並自動切換為進攻方 | **短按 (Tap)** 選手名、總分、或單局得分格 |
| **該選手單局犯規 +1** | **短按 (Tap)** 單局犯規框 |
| **數值 -1** (防呆扣分) | 在任何得分或犯規格子 **長按 0.6 秒** |
| **分數結算**並進入下一局 | 當兩側單局得分相加等於 **14** 時，點擊出現的 **橘色大按鈕** |
| **切換顯示模式**或**結束比賽** | 點擊「全螢幕」或「回主大廳」按鈕 |

---

## 核心功能

* **大廳與計分雙模式**：支援選手姓名自訂、Race 搶分點數設定，並透過 `localStorage` 實現跨頁面資料同步。
* **智慧結算系統**：系統自動執行 `總分 = 舊總分 + 單局得分 - 犯規次數` 之結算邏輯，且總分設有最低為 0 的保護機制。
* **條件式按鈕顯示**：結算按鈕僅在兩邊單局得分達標時（14 分）自動出現，保持介面在比賽進行中的簡潔度。
* **進攻方動態高亮**：根據加分動作自動以橘色邊框標示當前進攻選手，方便裁判與選手即時辨識。
* **極致對齊佈局**：針對行動裝置精密計算中間控制區與兩側方框的相對位置，確保在各類螢幕尺寸下皆能維持完美水平對齊。
